# Automehanika Prijić

Višestranična web stranica za zamišljeni automehanički servis iz Koprivnice.
Stranica predstavlja usluge servisa, okvirne cijene i termine rada te ima
kontakt obrazac za zakazivanje servisa. Oblikovanje je napravljeno isključivo
Tailwind CSS klasama uključenima putem CDN-a, a stranica se prilagođava
mobitelima, tabletima i računalima.

## Stranice

- `index.html` – naslovnica s predstavljanjem servisa i istaknutim uslugama
- `usluge.html` – popis usluga s terminima rada
- `kontakt.html` – kontakt obrazac za zakazivanje servisa

## Mape

- `slike/` – logo servisa (`logo.svg`)
